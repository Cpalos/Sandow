Politique de confidentialité

Dernière mise à jour : mai 2025
En résumé : Sandow ne collecte, ne stocke et ne transmet aucune donnée personnelle vous concernant. Toutes vos préférences restent sur votre appareil. Nous ne vous traçons pas.

Présentation

Sandow est une application d'aide à la décision pour la chasse sous-marine. Elle analyse les conditions météorologiques marines, les marées et vos préférences personnelles pour vous recommander les meilleurs créneaux de sortie.

Données collectées

Sandow ne collecte aucune donnée personnelle. L'application fonctionne entièrement en local sur votre appareil. Les seules informations utilisées sont :

  • Votre localisation géographique (ville ou coordonnées GPS), utilisée uniquement pour interroger les API météo — elle n'est jamais transmise à nos serveurs
  • Vos préférences de chasse (créneaux horaires, seuils, spots favoris) — stockées exclusivement dans la mémoire locale de votre appareil
Nous ne disposons d'aucun serveur, d'aucune base de données, d'aucun compte utilisateur. Il n'existe aucun moyen pour nous d'accéder à vos données.

Services tiers

Pour afficher les conditions météo et marines, Sandow interroge directement depuis votre appareil :

  • Open-Meteo (open-meteo.com) — météo atmosphérique et marine, API gratuite open-source
  • Open-Meteo Geocoding — résolution des noms de villes en coordonnées GPS

Ces services reçoivent uniquement vos coordonnées géographiques pour retourner les données météo. Aucun identifiant personnel n'est transmis. Politique d'Open-Meteo : open-meteo.com/en/terms

Localisation GPS

Si vous autorisez l'accès à votre position GPS, celle-ci est utilisée uniquement pour interroger les API météo. Elle n'est pas stockée de façon permanente et n'est jamais partagée. Vous pouvez révoquer cet accès à tout moment dans les réglages de votre appareil.

Notifications push

Les notifications sont gérées entièrement par votre appareil. Sandow utilise des minuteries locales déclenchées par l'analyse des données météo en cours de session. Aucune notification n'est envoyée depuis un serveur externe.

Données stockées localement

Les données suivantes sont enregistrées dans le stockage local de votre navigateur, sur votre appareil uniquement :

  • Vos préférences (seuils de vent, houle, marée)
  • Vos créneaux de chasse favoris et vos jours disponibles
  • Vos spots enregistrés (nom, coordonnées, notes)
  • Votre localisation par défaut

Ces données ne quittent jamais votre appareil. Vous pouvez les supprimer à tout moment en vidant les données de l'application dans les réglages de votre appareil.

Cookies et traçage

Sandow n'utilise aucun cookie, aucun pixel de traçage, aucune technologie d'analyse d'audience. Nous ne savons pas combien de personnes utilisent l'application.

Mineurs

Sandow ne collectant aucune donnée personnelle, l'application ne présente aucun risque particulier pour les utilisateurs mineurs.

Modifications

Cette politique peut être mise à jour pour refléter des évolutions de l'application. La date de dernière modification est indiquée en haut de cette page.
